# TASK: Generate Post IG
**Squad:** mvp-media
**Role:** media-content & media-visual

# OBJECTIVE
Gerar um post estático completo pronto para o Instagram.

# INPUTS
- Pauta do dia gerada pelo `media-master`.
- Tom de voz e segmento (`client-template.json`).

# INSTRUCTIONS
1. O `media-visual` cria a instrução da imagem. Ex: "Foto do produto X em fundo claro".
2. O `media-content` escreve o texto completo usando a estrutura Gancho -> História -> CTA.
3. Combine tudo no formato final.

# EXPECTED OUTPUT
Markdown formatado contendo: (1) Sugestão visual da foto/arte, (2) Legenda completa, (3) Hashtags.
