# TASK: Generate Story IG
**Squad:** mvp-media
**Role:** media-content

# OBJECTIVE
Criar uma sequência de stories focada em prender a atenção (retenção) e vender (conversão).

# INPUTS
- Objetivo de conversão ou engajamento do dia.

# INSTRUCTIONS
1. Stories não são posts soltos, são *sequências*.
2. Estrutura padrão:
   - Slide 1: Enquete ou Pergunta chamativa (Quebra de padrão).
   - Slide 2 e 3: Educação ou demonstração do problema.
   - Slide 4: Solução (O produto/serviço do cliente).
   - Slide 5: Chamada pro Link (WhatsApp).
3. Especifique os stickers que o cliente deve usar (Ex: Caixinha de perguntas, enquete).

# EXPECTED OUTPUT
Roteiro claro de 3 a 5 slides contendo o que deve estar na tela (foto/texto) e qual sticker usar em cada um.
