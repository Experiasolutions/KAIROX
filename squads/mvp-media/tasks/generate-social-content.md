# Task: Gerar Pauta Semanal de Conteúdo

**Objetivo:** Criar 3 posts semanais usando a estratégia Pareto ao Cubo e o template de prompts.

## Instruções Passo a Passo

1. Leia o arquivo `clients/_template/media/ig-post-prompt.md`.
2. Para cada cliente (ex: Leticia), defina 3 objetivos para a semana:
   - 1 Post Educativo (Autoridade)
   - 1 Post Prova Social (Case)
   - 1 Post de Venda Direta
3. Gere o conteúdo completo (hook, corpo e CTA) seguindo rigorosamente a estrutura pedida no prompt.
4. Salve os resultados em `clients/{{CLIENT_ID}}/media/pauta-semanal.md`.
5. Notifique o cliente via WhatsApp com as ideias de postagem aprovadas.
