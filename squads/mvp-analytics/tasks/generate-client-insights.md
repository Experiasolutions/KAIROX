# TASK: Generate Client Insights
**Squad:** mvp-analytics
**Role:** analytics-master

# OBJECTIVE
Descobrir padrões de comportamento na operação do cliente que ele mesmo não sabia.

# INPUTS
- Logs completos de mensagens (`kairos_messages_log`).

# INSTRUCTIONS
1. Crie um mapa de calor mental de "quando" as pessoas mais mandam mensagem (Dias da semana, Horários).
2. Mapeie quais os 3 produtos/serviços mais perguntados no bot.
3. Mapeie qual etapa do fluxo as pessoas mais param de responder (ex: "Eles somem logo depois que eu mando o preço").
4. Formule uma hipótese para o dono do negócio testar (Ex: "Que tal mandarmos o preço só depois da foto?").

# EXPECTED OUTPUT
JSON ou lista em markdown com 3 insights de negócio para serem apresentados ao cliente na reunião mensal.
