# TASK: Generate Weekly Report
**Squad:** mvp-analytics
**Role:** analytics-report

# OBJECTIVE
Gerar um relatório fácil de entender com os principais KPIs da semana.

# INPUTS
- Dados fornecidos pelo `analytics-master`.

# INSTRUCTIONS
1. Verifique os dados:
   - Total de contatos.
   - Total de novos vs retornantes.
   - Orçamentos emitidos.
2. Formate o texto focando em crescimento ou atenção ("Ganhamos 10% a mais de contatos nessa semana!").
3. Finalize com um "Você sabia?" (dado curioso da operação).

# EXPECTED OUTPUT
Relatório semanal pronto para envio no WhatsApp do cliente toda sexta-feira 18:00.
